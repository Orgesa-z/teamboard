# Teamboard

A real-time collaborative task board. Changes appear instantly for everyone on the board.

**Live demo:** https://teamboard-tlw7.onrender.com/

## Features
- Add, move (drag and drop) and delete notes
- Live updates across all connected users with WebSockets
- See who is online
- Notes are saved on the server

## Tech stack
Node.js, Express, Socket.io, vanilla JavaScript, HTML/CSS

## Run locally
    npm install
    npm start
Then open http://localhost:3000
